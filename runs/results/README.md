One trial per file: `runs/results/<job-id>/<task-id>-<checkpoint>-<arm>-<trial>.json`, where `<checkpoint>` is the `tool_call_id` or `step0`. It must validate against `contracts/replay-result.schema.json`. The sample size is the number of files for that job, task, checkpoint, and arm. `cost_credits` comes from `tokenUsage.factoryCredits`. `evidence_role` is `diagnosis` for a `checkpoint` trial and `final` for a `step0` trial.
