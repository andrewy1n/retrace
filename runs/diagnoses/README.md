One diagnosis per session: `runs/diagnoses/<session-id>.json`, written by `analysis/features/diagnose.py`. The fields are `session_id`, `task_id`, `target`, `value`, `first_edit_tool_call_id`, `cited_tool_call_ids`, `counts`, `pattern`, and `explanation`. `summary.json` holds the pattern counts and the unexplained sessions. Diagnoses cite `tool_call_id`s and counts only, never tool input or output. Kate writes these. Andrew does not read them. He gets them only as replay jobs.
