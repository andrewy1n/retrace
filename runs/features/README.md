One feature record per session: `runs/features/<session-id>.json`, written by `analysis/features/compute.py --out runs/features`. The fields are `session_id`, `hard_signals`, `failure_type`, `suspected_tool_call_id`, `pending`, and `features`. Kate writes these. Andrew does not read them. The allowed values are in `analysis/AGENTS.md`. Friction tickets that group these sessions live in `runs/tickets/`.
