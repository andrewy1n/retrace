One markdown file per frozen comparison, named for the failure group. Include the setup, the count, the interval, the Factory credits, and the evidence label. The held-out comparison has three arms, all fresh from step 0: unmodified Droid, a transcript-only rule, and the replay-derived change. Result tables stay here. The project doc stores the git SHA, not the numbers. Grader results here are for people. The improvement loop does not read them. Each report ends with a proxy agreement section. It shows how well each proxy agrees with the grader on `final` trials, as counts, a Wilson interval, and Cohen's kappa. It is for verification only.

`preregistration.md` states the claim, the metrics, and the arm B prompt. Commit it before the first derivation run. Change it only in a new commit that names the change, and only before held-out runs start.
